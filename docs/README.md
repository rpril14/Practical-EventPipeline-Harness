# Documentation Map

This directory holds the harness operating files and product contracts for the
EventPipeline project.

## Main Files

- `HARNESS.md`: how humans and agents collaborate on this project.
- `FEATURE_INTAKE.md`: how prompts become tiny, normal, or high-risk work.
- `ARCHITECTURE.md`: architecture discovery and boundary rules.
- `TEST_MATRIX.md`: living map of behavior to proof.
- `HARNESS_BACKLOG.md`: improvements discovered while working.
- `GLOSSARY.md`: shared terms.

## Folders

- `product/`: product contracts derived from the EventPipeline spec.
- `stories/`: story packets and backlog across 4 epics.
- `decisions/`: durable decisions and tradeoffs.
- `templates/`: reusable spec-intake, story, decision, and validation formats.
